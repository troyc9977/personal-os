# Inbox

Capture-first dump zone. Process Sundays. Don't filter at capture.

## Rules

1. Anything goes. A sentence is fine. A fragment is fine.
2. No formatting required.
3. Newest at top.
4. Process every Sunday during weekly review (~15 min).
5. After processing, items move to: a project file, a decision file (ADR), a task, or trash.

## Processing fates

For each item on Sunday:

1. **Trash** — delete.
2. **Do now** — under 2 minutes, handle in the review.
3. **Project update** — append to the relevant file in `docs/projects/`.
4. **Decision** — promote to a numbered ADR in `docs/decisions/`.
5. **Reading** — add to `docs/reading.md`.
6. **People** — note in `docs/people.md`.
7. **Note** — file under `docs/notes/YYYY-MM-DD-name.md` if it deserves a real essay.

After processing, the file is empty below the rules section. Date headers stay as a record of capture cadence.

## Capture surfaces

- Browser: github.com web UI, edit this file.
- Phone: GitHub mobile app, or iOS shortcut later (Phase 4).
- Personal machine: local editor, commit and push.
