# Weekly — May 2026

One file per month. Each week appended at the bottom. Compass dashboard reads/writes this file.

## Format

Each weekly entry has four sections:

```
## Week of YYYY-MM-DD (Date range)

### This week's three
1. [Title] — [why this is top-3]
2. [Title]
3. [Title]

### Tasks pool
- [ ] [tN] Task title (big)
- [ ] [tN] Task title

### Sunday review (past + coming)
**Last week:**
- 1: [hit / partial / miss] | [what blocked]
- 2: [hit / partial / miss] |
- 3: [hit / partial / miss] |

**Habits:**
- Meditation: X/7
- Runs: X/4
- Stretching: X/3
- No bad habit: X/7

**What I learned:**
[paragraph]

**Drift signals:**
[anything I notice]

**Notes for Matthew:**
[cross-cutting WardForge items]

### Next week's three
1.
2.
3.
```

## Rules

- **Three big items per week.** Each becomes a `(big)` task in the pool. The discipline is choosing.
- **Tasks pool is unbounded for small tasks**, but should stay reasonable (~10-15 max). If it's growing, that's a signal something isn't getting done.
- **Big tasks have a Why, captured in the "This week's three" section.**
- **Tasks roll over.** Incomplete tasks at end of week move to next week's pool automatically. Compass handles this on Sunday.
- **Sunday review is one sitting.** Past-week review + next-week setup. ~20-30 min.
- **Habit summary is computed from daily file.** Compass handles this aggregation.

## Task IDs

- IDs are unique within a week (`t1, t2, t3...`). Reset each week.
- IDs are stable across daily/weekly files for the same task.
- Compass dashboard manages ID assignment.
