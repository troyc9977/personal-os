# Daily — May 2026

One file per month. Each day appended at the bottom. Compass dashboard reads/writes this file.

## Format

Each daily entry has three required sections (Today, Habits) and one optional section (Retrospective).

```
## YYYY-MM-DD (Day)

### Today
- [ ] [tN] Task title (big)
- [ ] [tN] Task title

### Habits
- [ ] Meditation
- [ ] Run
- [ ] Stretching
- [ ] No bad habit

### Retrospective (optional)
[free text if I want]
```

## Rules

- **Tasks come from the weekly pool.** Each task has a `[tN]` ID that matches its entry in `weekly/YYYY-MM.md`. Compass dashboard handles ID assignment.
- **Tasks marked `(big)` are part of "this week's three."** Max 3 big per week.
- **Max 3 big tasks pulled into a single day.** Small tasks have no cap.
- **Habits are binary.** Quantity goes in retrospective if it matters.
- **Retrospective is optional.** Skip when there's nothing to say.
- **Task completion syncs across daily and weekly files.** Compass handles this automatically.

## Reading log lives in `docs/reading-log/YYYY-MM.md`, not here

Keeps the daily file scannable and the reading record clean.
