# Reading Log — May 2026

One file per month. New entries appended at the bottom. Date, book, page numbers. Notes optional.

The point: a real artifact accumulating over years. By the end of 2026 there are 12 of these files. By 2030 there are 60. The cumulative record of what I've actually read becomes the most honest measure of the reading practice.

## Format

```
## YYYY-MM-DD (Day)
- Book Title, pp. X-Y
- (optional: brief note, quote, reaction)
```

## Rules

- Page numbers tracked. Time spent does not get tracked here.
- Multiple books in one day = multiple lines.
- Skipped days are okay. Don't backfill.
- Substantial notes/quotes go in `docs/notes/YYYY-MM-DD-bookname.md` instead. Keep this file scannable.
- No targets, no minimums. Just the record.
