# Decisions

Personal ADRs. One file per meaningful decision.

Format: `NNNN-short-name.md` (e.g. `0001-personal-os-exists.md`).

## Pattern

Each ADR has:

- **Title**: numbered, hyphenated.
- **Status**: Proposed / Accepted / Superseded / Reversed.
- **Date**: when accepted.
- **Context**: what's the situation that requires a decision.
- **Decision**: what I am actually deciding, in one short paragraph.
- **Consequences**: what changes because of this. Positive, negative, neutral.
- **Alternatives considered**: what I rejected, briefly.

## What counts as a "decision"

Anything I might want to remember in 6 months. Examples:

- Major life shifts (moves, jobs, relationships).
- Financial commitments above a threshold.
- Project starts and project sunsets.
- Stance changes (something I believed, now I don't).
- Standing rules I am committing to (e.g. "I will not pitch journalists about WardForge until X").
- Anything I would feel weird if I forgot the reasoning behind.

## What does NOT count

- Tasks. Those go in project files or task tools.
- Daily preferences (what to make for dinner).
- Things I'm just thinking about. Those stay as notes until they actually become decisions.

## Discipline

Within 24 hours of making a meaningful decision, write it up. The act of writing is half the value — it forces the question "what am I actually committing to?"

Reverse decisions when I change my mind. Don't quietly drift away from them. A reversal is itself an ADR (`0042-reverse-0017-substack-cadence.md`).
