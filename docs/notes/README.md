# Notes

Free-form dated thinking. The space for things that don't fit anywhere else.

Format: `YYYY-MM-DD-short-name.md`.

## What goes here

- Essays-in-progress that aren't ready for Substack.
- Long thoughts on books.
- Trip reports, conversation notes, recurring themes.
- Half-formed ideas worth keeping.

## What doesn't go here

- Daily journaling. (No daily journaling discipline; only when I have something to say.)
- Tasks.
- Anything that belongs in a project file or decision file.

## Discipline

When something I'm capturing in inbox feels like it deserves more than a bullet, promote it to a note here. When something a note here matures, it might become a Substack draft, an ADR, a project update, or a weekly state's "what I learned" section.

Notes are not sacred. Some will get archived, deleted, or absorbed into other documents. That's correct.
