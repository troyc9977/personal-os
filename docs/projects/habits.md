# Habits

The four tracked habits and their targets.

Last reviewed: 2026-05-03

## What's tracked

- **Meditation** — daily, 10 min minimum. Per ADR-0003.
- **Run** — 4x/week target. Building back from current 2-3x.
- **Stretching** — 3x/week target. Building from negligible.
- **No bad habit** — daily. Kept general intentionally; the specific shape stays private to me.

## Why these four

- Meditation is the contemplative floor. Without it, the interior cylinder dies.
- Running is the cardio base — health, weight management, mental clarity, embodiment.
- Stretching is the longevity layer. Boring, ignored, important.
- "No bad habit" covers the things I don't want to write down explicitly but want to track. The kind of personal accountability that doesn't need granular naming to work.

Writing is deliberately NOT a daily habit. Writing happens in milestones (outline, draft, revise), tracked in weekly goals, not in binary daily checkboxes.

## How it works

- Daily file in `docs/daily/YYYY-MM.md` has a habit checkbox section per entry.
- Sunday weekly review aggregates the week's hits into the weekly file.
- Quarter file sets quarterly habit targets.
- No streak counting. No quantified-self overlay.
- The point is noticing patterns and catching drift, not enforcing compliance.

## Drift signals

Things that should surface concern, not panic:

- Any habit at <50% for 2 weeks running.
- Meditation specifically — if it dies, the response per ADR-0003 is to reduce or restructure (5 min, walking practice, etc.), not white-knuckle.
- All four habits dropping in the same week — something else is wrong, look at the rest of life.

## Adding or removing habits

- Don't add new habits without removing one or proving the existing four are stable for at least a month.
- Remove a habit when it's either become automatic (no longer needs tracking) or proven irrelevant.
- Changes to the habit list require updating ADR-0005 explicitly.

## What to do when the system itself starts feeling like a chore

This is the real long-term risk. If the daily checkbox routine starts feeling performative or anxiety-inducing:

1. Reduce. Drop to 2 habits instead of 4. The point is the habits, not the tracking.
2. Restructure. Move habit checks to weekly aggregation only — track presence, not daily ticks.
3. Pause. A two-week pause where you just live without the system, then return if it's actually missed.

The goal is a tool that serves life, not a life that serves the tool.
